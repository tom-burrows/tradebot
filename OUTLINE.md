# Foreign Exchange Trading Bot

The aim of this project is to create a Foreign Exchange Trading Bot

## Where will it trade?

The bot will be able to trade in a fully automated way, but will only be trading on a Demo Account.

## How will I interact with it?

When this project is completed, the project will only consist of a backend. This means that all interaction with the bot:
- Updating rules
- Turning on/off
- Reiewing performance

Will all be done via API calls. This is because I will be building a new project later down the line, which will act as a front-end for this project.


## Things to consider

Once the project is complete, it should require a log-in to access. This is because it will eventually be hosted live on the internet, and will be used in my CV as an example project. This means that security is a very important consideration from the start.

## Information about the bot itself

This is my first algorithmic trading bot that I'm making myself, and it's definitely a learning journey for me. The main thing I'm focusing on for this bot itself, especially in the beginning stages, is that I want a bot that relies on speed: an arbitrage bot that does that sort of stuff. It's going to be low latency, and the algorithmic trading strategy is going to be very dependent on latency. I'm sort of relying on you a little bit to fill in the gaps there, but that's the main aim.
